AI summary
Removing a coupon triggers an optimistic cart update. When the API rejects the stale revision, the rollback restores the values but does not release the checkout lock.
92% confidence
Likely root cause
The failure path in useCart.ts catches the 409 response but exits before setCheckoutLocked(false) executes. The error is consistent with the captured stack and interaction sequence.
